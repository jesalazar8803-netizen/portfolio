# 🖥️ Portafolio de Proyectos — Windows 11 / Fluent Design

Sitio independiente de GitHub Pages para presentar proyectos de desarrollo de software.

## Objetivo
Mantener la hoja de vida enfocada en el perfil profesional y utilizar este sitio como portafolio técnico independiente.

## Características
- Estética inspirada en Windows 11 / Fluent Design.
- Tema oscuro con Acrylic/Mica.
- Tarjetas con profundidad 3D.
- Carrusel con botones, indicadores, teclado y touch.
- Filtros: Todos, Java, Web, Escritorio y En desarrollo.
- Enlaces directos a GitHub.
- Diseño responsive.
- Sin backend ni base de datos.

## Tecnologías
HTML5 · CSS3 · JavaScript ES6+ · Git · GitHub · GitHub Pages

## Estructura
```text
portfolio-windows11/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## Proyectos
1. Sistema Inventario C#
2. Java MVC – Gestión de tareas
3. Formulario CRUD – Personas
4. CRUD – Usuarios
5. 📚 Biblioteca Inteligente
6. Actualización Aquality Store
7. Sistema Gestión de Estudiantes

## Publicación
Sube los archivos a un repositorio y activa GitHub Pages desde `Settings → Pages`, seleccionando la rama y `/root`.
