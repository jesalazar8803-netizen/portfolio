02 · SOBRE EL PORTAFOLIO

De ejercicios a proyectos con arquitectura.

Este portafolio reúne trabajos que muestran una progresión de aprendizaje: fundamentos de programación, interfaces de escritorio, CRUD, desarrollo web, bases de datos y proyectos orientados a backend.

Los proyectos en desarrollo funcionan como laboratorio para consolidar Java, Spring Boot, SQL, APIs, Git y buenas prácticas de ingeniería de software.
